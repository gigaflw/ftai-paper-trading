# 插件市场图标

上架时在管理端「桌面端插件市场」上传这里的图；市场只收 PNG / JPEG / WebP，单张不超过 256 KiB，
列表与详情页共用这一张。应用内的侧栏与设置页图标不在这里——那是 Tabler 的 React 图标组件，见 `src/client/index.ts`。

| 文件 | 尺寸 | 大小 | 用途 |
|---|---|---|---|
| `paper-trading-icon-512.png` | 512×512 | 189 KiB | 上架上传（1:1，2×/3× 屏够用） |
| `paper-trading-icon-256.png` | 256×256 | 49 KiB | 列表缩略备用 |

## 构成与配色

- 实线账本页（左上，折角）+ 平滑上升箭头 + 虚线影子副本页（右下）＝「实盘 + 模拟副本」。
- 底 `#14213D`（深墨蓝）、页面与虚线 `#F6F1E7`（暖米白）、箭头 `#E03A3A`（朱红）。
- 扁平矢量，无渐变、无阴影、无文字；缩到 32px 仍可辨。

## 重新生成

用 gpt-image-2 按「flat vector app icon、rounded square tile、单一主体、无文字」出 1024 方图，
再裁方缩到 512 / 256 并压到 256 KiB 以内。换配色只改三个 HEX：底色、页面色、箭头色。
